# 🧠 Тест по истории

Интерактивный браузерный тест по истории России и мира.  
200 обязательных вопросов выбираются случайно из базы в 300 — без повторов и пропусков.  
Результат оценивается по 5-балльной системе.

## 🚀 Демо и запуск

**Играть онлайн:** откройте опубликованную страницу GitHub Pages  
(адрес появится в разделе **Settings → Pages** вашего репозитория).

**Локальный запуск:**  
Скачайте проект и откройте `index.html` в любом современном браузере — без сборки, сервера и интернета (кроме шрифтов Google Fonts).

## 🎮 Как играть

1. Нажмите **«Начать тест»**.
2. Отвечайте на вопросы:
   - клик по варианту или
   - клавиши **1–4**.
3. Нажмите **«Дальше»** или **Enter**, чтобы перейти к следующему вопросу.
4. После 200 вопросов вы увидите оценку, статистику и комментарий.

## 📊 Система оценивания

| Процент правильных | Оценка |
|--------------------|--------|
| ≥ 90 %             | 5      |
| ≥ 70 %             | 4      |
| ≥ 50 %             | 3      |
| < 50 %             | 2      |

## ✨ Возможности

- 300 вопросов в базе (Древняя Русь, Московское царство, Российская империя, СССР, современная Россия, всемирная история)
- Случайная выборка 200 вопросов за прохождение
- Случайный порядок вариантов ответа
- Визуальная шкала прогресса в виде линейки
- Тёмная и светлая темы (автоматически по системным настройкам)
- Адаптивная вёрстка для телефонов, планшетов и десктопа
- Управление с клавиатуры
- Поддержка `prefers-reduced-motion` и безопасных зон iPhone
- Без внешних зависимостей и сборки
