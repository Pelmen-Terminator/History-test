# 📜 Тест по истории — версия 1.1

Интерактивный тест по истории России и всемирной истории.

## 🎯 Возможности

- **300 вопросов** в базе (пронумерованы от 1 до 300)
- Каждый тест состоит из **20 случайных вопросов**
- Вопросы **не повторяются** внутри одного теста
- Варианты ответов **перемешиваются** каждый раз
- Оценка по **5-балльной системе**:
  - **5** — 90–100% правильных ответов
  - **4** — 70–89%
  - **3** — 50–69%
  - **2** — менее 50%
- **Случайные комментарии** к итоговому результату
- Прогресс-бар и live-счётчик правильных ответов
- Адаптивный дизайн (работает на телефоне и ПК)
